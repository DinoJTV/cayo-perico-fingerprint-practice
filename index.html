OPERATOR GUIDE

FOLLOW THE RIDGES

01 / Find the top.
Cycle the first row until it matches the very top of the target on the right.

02 / Use the sequence.
Every row cycles through the same eight slices in top-to-bottom order. For row two, find that same top slice, then move right once. For row three, move right twice. Continue to row eight: top slice + seven.

03 / Clone the signal.
All eight matching rows trigger CLONE MATCH. Complete every fingerprint before the connection timer expires. The scramble timer reshuffles your current print.
